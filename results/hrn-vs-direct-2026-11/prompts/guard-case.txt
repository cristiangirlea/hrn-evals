Windows resolves program names case-insensitively, but three of the guard's rules in internal/tools/guard.go match the program name in one case only: disk (`Format D:` or `FORMAT D:` passes), pipe-to-shell (`curl ... | PowerShell -` passes, and `| iex` / `Invoke-Expression` is not matched as a shell at all), and sudo (Windows 11 ships sudo, and `Sudo` passes). Make the program-name part of these three rules case-insensitive on every platform, and make pipe-to-shell also match irm and iwr as downloaders and iex and Invoke-Expression as the shell, with tests in internal/tools/guard_test.go. Tools whose subcommands are case-sensitive (gh, kubectl, docker, helm, terraform) need no change. Do not run git on this repository.
