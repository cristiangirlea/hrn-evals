hrn watch --public exempts page navigations (GET or HEAD with Sec-Fetch-Mode: navigate) from the Origin check in the guard handler of internal/watch/server.go. That exemption also covers iframe, object and embed loads, which carry the same mode. Require Sec-Fetch-Dest: document as well, so that only top-level page loads are exempt: a cross-site GET with Sec-Fetch-Dest: iframe, or with no Sec-Fetch-Dest at all, is refused with 403 and logged with the reason "bad origin", while a cross-site GET or HEAD with Sec-Fetch-Dest: document and a valid token still passes. Add the cases to internal/watch/access_test.go. Do not run git on this repository.
