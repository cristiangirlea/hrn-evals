hrn watch shortens a quoted program path in a system folder to its file name ("C:\Program Files\Git (Preview)\bin\bash.exe" becomes "bash.exe"), but a double-quoted path whose folder contains an apostrophe ("C:\Program Files\Bob's Tools\tool.exe" --help) is still shown in full, because the scan in the function program in internal/watch/paths.go stops at either quote character. Inside a single-quoted path in JSON text, an unescaped double quote still ends the scan, since it closes the JSON string, so an unterminated single quote stops at the string's end and the next field is kept; an even run of backslashes before that double quote escapes only itself.
