In internal/remote/client.go, Watch treats only ErrMalformedEvent and ErrEventOutput as terminal and resets its failure count on every 200 response, so an SSE line over 1 MiB (the scanner in ReadEvents fails with bufio.ErrTooLong) is fetched again from the same cursor once a second, for ever. Make ReadEvents report such a line as an error whose text says "event line exceeds 1 MiB limit" and that wraps bufio.ErrTooLong, and make Watch return that error instead of retrying, so a server that sends an oversized line is asked exactly once. Add a test in internal/remote/client_test.go that Watch returns the error after one request. Do not run git on this repository.
