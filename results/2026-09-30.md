## Against the publication gate

Checked against [the publication gate](../docs/publication-gate.md), using the three
named saved evals and their batch records. This baseline does not qualify for a saving
or quality-difference claim.

- [ ] 1. **Cases, repetitions and pairing:** partially met. The saved specs pair both
  arms on identical tasks, but contain only three cases in total and one repetition per
  arm, below the required six cases and three repetitions.
- [x] 2. **Complete scoring:** met for the named evals. All six attempts are accounted
  for in their tables and batches; each has all its suite gates recorded, with successful
  exit codes. No run from these evals was dropped. This does not establish whether other,
  unnamed evals existed.
- [ ] 3. **Usage and cost:** partially met. No token total or saving is published, so
  there is no provider-only, unweighted token aggregate to check. The displayed Claude
  costs match the rounded costs in the saved attempt results, but the page does not state
  whether they are provider-reported or estimated. Codex costs are left unclaimed; zero
  cost fields in its eval tables do not establish free runs.
- [ ] 4. **Negative and no-op cases:** not established. All named cases are shown, but
  the page and saved specs do not identify negative or no-op cases, and no aggregate
  retaining them is reported.
- [ ] 5. **Uncertainty:** not met. No 95% case-bootstrap interval from 10,000 resamples
  is reported, so there is no interval excluding zero to support a difference claim.
- [ ] 6. **Reproduction pins:** partially met. The page gives an hrn commit and eval
  ids accepted by `hrn eval diff`; the saved specs record the Claude model alias. It lacks
  the hrn version, exact Claude CLI version, an explicit Codex CLI version and model id,
  suite commit and fixture hashes. The batches record a repository base commit, but the
  page does not pin it; the Codex model is unspecified in the saved specs.
- [ ] 7. **Number basis:** partially met. The displayed run metrics are measured on
  this suite and agree with the saved records (durations and Claude costs are rounded).
  The page does not explicitly label every number measured, inferred or verified, and
  supplies no stated real-run window for a verified claim.
